# Laboratorios DOPO

Repositorio correspondiente a los laboratorios de la asignatura **Diseño y Orientación de Programación Orientada a Objetos (DOPO)**.

En este repositorio se almacenan los diferentes laboratorios desarrollados durante el curso, junto con sus respectivos códigos fuente, recursos y documentación.

## 📚 Contenido

### Lab 01 — Robot Maze

Primer laboratorio de la asignatura. Se desarrolla un sistema basado en programación orientada a objetos en Java, utilizando un robot que se desplaza dentro de un tablero con paredes y un objetivo.

**Temas trabajados:**

- Clases y objetos
- Encapsulamiento
- Constructores
- Métodos
- Arreglos
- `ArrayList`
- Relaciones entre clases
- Programación orientada a objetos
- Algoritmos de búsqueda
- Movimiento y navegación dentro de un laberinto

## 🛠️ Tecnologías

- **Lenguaje:** Java
- **IDE:** BlueJ
- **Control de versiones:** Git
- **Repositorio remoto:** GitHub
